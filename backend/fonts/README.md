# Arabic fonts for invoice PDF reports

Place an Arabic-capable TTF font here for correct rendering of Arabic text in the bilingual invoice PDF.

**Supported filenames** (checked in order):

- `NotoNaskhArabic-Regular.ttf`
- `Amiri-Regular.ttf`
- `NotoSansArabic-Regular.ttf`

**Download:**

- Noto Naskh Arabic: https://fonts.google.com/noto/specimen/Noto+Naskh+Arabic
- Amiri: https://fonts.google.com/specimen/Amiri

Alternatively set `ARABIC_FONT_PATH` to the full path of your TTF file.

If no font is found, the PDF still generates; Arabic may not display correctly (Helvetica fallback).
